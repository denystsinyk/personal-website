# Denys Tsinyk — personal website

My personal portfolio: navy and gold, an illustrated shelf, and a little weather.

## Development

Requires Node.js 22.13 or newer.

```sh
npm ci
npm run dev
```

```sh
npm run build  # production build
npm start      # serve the production build
npm run lint   # lint JavaScript and type-check TypeScript
npm run format
```

## Where things live

- `app/page.tsx`: bio, experience, projects, and links.
- `app/globals.css`: styles and responsive layouts.
- `app/layout.tsx`: page metadata and initial color theme.
- `public/site.js`: theme toggle, signature, and weather effects.
- `public/assets/`: personal photo and original illustrated shelf.

Built with React, TypeScript, and Vinext/Vite. No database is required. The optional receipt scanning feature uses a server-side Gemini API key. The contact link opens the visitor’s email client.

## Configuration

- `package.json`: project scripts and dependencies.
- `package-lock.json`: exact dependency versions for reproducible installs; generated by npm.
- `tsconfig.json`: TypeScript settings.
- `vite.config.ts`: enables the framework’s build plugin.
- `next.config.ts`: configures static export for GitHub Pages.

Formatting and linting use their default configuration. Local agent metadata is ignored by Git and is not required to run the site.

## Publishing

Push to `main` to build and deploy the static site to GitHub Pages. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The site URL will be `https://denystsinyk.github.io/personal-website/`.

GitHub Pages serves static files, so receipt photo OCR runs in the browser and the Gemini API route is not deployed. Manual receipt entry and browser OCR are available. Social preview metadata points to the portrait under the Pages URL above.

Before publishing, confirm the Character.AI internship wording, graduation date, and roles labeled “present.” No résumé download is shown until a PDF is supplied.

## Receipt splitter

Open `/split` (also linked from the homepage). Supports photos, upload/drag-and-drop/paste,
manual entry, item assignments, proportional tax/fees/tip, cent-exact totals, copyable
breakdowns, and browser-local draft storage. Review scanned prices before sharing.
Adapted from [Shreyash Ranjan’s splitter](https://github.com/codingshreyash/codingshreyash.github.io/blob/main/split/index.html).

- `app/split/`: route, trusted static UI markup, and scoped theme styles.
- `public/split.js`: receipt editor, browser OCR, and split calculations.
- `app/api/split/scan/route.ts`: optional server-side Gemini endpoint for server hosting; it is not included in the GitHub Pages site.

On GitHub Pages, receipt photos are processed in the browser with Tesseract.js and its
English language data, which are downloaded from public CDNs when scanning. Photos are not
sent to this site's server or to Gemini. Scanning needs an internet connection; manual
entry always works. Drafts are stored in localStorage; reset clears the receipt and keeps
recent names. The optional API route is only used when deploying to a server that supports
Next.js route handlers; configure `GEMINI_API_KEY` there if enabling it. Never expose that
key with a `NEXT_PUBLIC_` or `VITE_` prefix.

Run the receipt calculation tests with `node --test --test-isolation=none tests/split.test.cjs`.
